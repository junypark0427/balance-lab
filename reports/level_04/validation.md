이는 중립 상태의 원본 표면 간 기하학적 측정입니다. 실제 통과는 별도로 물리 주행했습니다.
전체 구조의 모든 간격이 통로인 것은 아니며, 맞닿는 충돌 조각의 접합부는 통로 폭 측정에서 제외합니다.

## 4. 중앙 원형 충돌체의 정밀 분할

[OBJ 도구](../../scripts/maps/obj_geometry.gd)가 연결된 솔리드를 분리합니다.
볼록한 솔리드는 실제 꼭짓점으로 ConvexPolygonShape3D를 만듭니다.
볼록하지 않은 원호는 **원래 윗면 삼각형**에서 시작하여, 이웃 삼각형의 합집합이 볼록할 때만 병합합니다.
병합 후 볼록 껍질 면적과 원래 두 조각 면적 합이 같은지 검사하므로 원호의 오목한 쪽이나 통로를 채울 수 없습니다.
[Godot Geometry2D](https://docs.godotengine.org/en/stable/classes/class_geometry2d.html)의 convex_hull을 사용하며,
실제 높이 0..11을 따라 각 조각을 압출합니다.

원호 7개는 총 **68개 Convex 프록시**, 중앙 원기둥은 Convex 하나입니다.
다른 벽/원판까지 모델 전체 프록시는 **78개**이며, 바닥 1개와 외곽 4개도 같은 Platform AnimatableBody3D에 속합니다.
따라서 모델·바닥·외곽은 한 물리 몸체의 중심을 기준으로 함께 기울어집니다.
Concave/Trimesh, 큰 원통으로 빈 공간을 덮는 충돌, 수평 천장, 추가 움직이는 장애물은 없습니다.

ㄷ자 원본은 모서리에서 박스 둘이 겹칩니다. 충돌 프록시에서는 가려진 겹침 부분만 짧게 하여
외곽 합집합과 개구부는 그대로 두고 중복 부피를 제거했습니다. 시각 메시와 원본 파일은 그대로입니다.
원호 조각은 면끼리 맞닿으며 볼륨을 겹쳐 쌓지 않습니다. 모델 프록시의 작은 margin은 0.001입니다.

## 6. 실제 주행과 독립 검사의 구분

### 실제 엔진 연속 주행

InputEventKey의 A/D/↑/↓를 눌렀다 놓는 자동 제어가 기존 InputMap → TiltInput → 플랫폼 회전으로 전달됩니다.
센서 입력은 꺼져 있습니다. 공은 좌표/속도 직접 쓰기, 순간이동, 힘 주기, 충돌 비활성화 없이 움직입니다.

정적 경로 탐색은 목표점만 제공합니다. 실제 Goal.body_entered와 Mission Success가 발생해야 성공입니다.

이를 막기 위한 새 벽을 추가하지 않고, 안쪽 기믹의 실제 통과를 별도 경유 주행으로 확인했습니다.

입력 전달, 각도 제한, 실제 미로 주행, 성공 처리는 별도의 통과 검사로 확인했습니다.

일부 제한된 headless 로그에는 macOS 인증서 조회나 사용자 로그 파일 쓰기 권한 메시지가 있습니다.
최종 별도 권한의 편집기·Metal 실행에는 이 메시지나 Script/Resource 오류가 없습니다.

## 8. 최종 레벨 완료 흐름

레벨 목록은 기존처럼 실제 Scene이 있는 항목을 모두 선택할 수 있게 합니다. 새로운 순차 해제 조건은 만들지 않았습니다.
LEVEL SELECT에 4번째 카드를 추가했고 기존 카드 디자인/버튼을 그대로 사용합니다.
완료 시 기존 결과 패널에 `FINAL EXPERIMENT COMPLETE`와 짧은 최종 단계 완료 문구만 추가합니다.
다른 레벨의 기본 완료 문구는 그대로입니다. RETRY는 LEVEL 04를 다시 열고 LOBBY는 기존 메인 메뉴로 갑니다.
LEVEL 05 항목·자동 다음 단계 전환·새 엔딩 Scene은 없습니다. 잘못된 인덱스 4 호출도 메뉴를 유지하는지 검사했습니다.

이 문구는 LEVEL 04 완료를 뜻하며, 다른 세 레벨의 진행도 저장이나 클리어 이력까지 새로 구현했다는 의미는 아닙니다.

## 10. 직접 확인할 사항과 재실행

두 사람의 긴 키 조작, 좁은 틈에서의 체감 난이도·키보드 동시 입력, 긴 시간 플레이,
다른 GPU/화면 비율의 가림 처리와 성능은 직접 확인이 필요합니다.
자동 제어의 약 95초는 사람의 클리어 시간 또는 난이도 보장이 아닙니다.
플레이가 성공했다는 결과를 모든 속도·모든 자세의 관통/탈출이 불가능하다는 보장으로 사용하지 않습니다.
FPS 정량 벤치마크나 실제 센서·네트워크 협동은 이번 검증에 포함하지 않았습니다.
기존 LEVEL 01 F3 진단 패널 겹침도 남아 있습니다.

프로젝트 폴더에서 Godot 4.7.2 실행 파일로 다음을 실행할 수 있습니다.

```sh
Godot --headless --path . --editor --import
Godot --headless --path . --fixed-fps 60 --script res://tests/level_04_test.gd -- --keyboard --inner
Godot --headless --path . --fixed-fps 60 --script res://tests/level_04_geometry_test.gd
Godot --headless --path . --fixed-fps 60 --script res://tests/ui_flow_test.gd
Godot --path . --fixed-fps 60 --max-fps 240 --script res://tests/level_04_test.gd -- --keyboard --inner --capture
```

출력 임시 폴더는 `/tmp/balance-level04/`이며 재실행 시 갱신됩니다.
