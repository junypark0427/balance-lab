### 관성·제동 비교

게임에서 읽은 일반/ICE 물리 프로필을 동일한 구체·넓은 평면의 통제 실험에 적용했습니다.
초기 충격량을 한 번 준 뒤 3초 동안 실제 Jolt 프레임을 진행했습니다.
이 실험은 미로 완주가 아니라 마찰·감쇠 비교입니다.

| 값 | 일반 | ICE |
| --- | --- | --- |
| 초기 안정 측정 X 속도 | 2.37094 | 2.97681 |
| 3초 후 X 속도 | 1.28254 | 2.29396 |
| 속도 유지 비율 | 약 54.1% | 약 77.1% |
| 최대 ±15도 범위의 반대 기울기 후 방향 반전 | 약 1.35초 | 약 2.00초 |

접촉 마찰이 달라 초기 측정 속도부터 차이가 있습니다. 속도 값을 강제로 같게 맞추지는 않았습니다.
ICE에서 관성이 더 오래 유지되고 기울기로 제동할 수 있다는 제한된 물리 근거입니다.
모든 미로 구간의 제어 가능성을 입증한 것은 아닙니다. 미끄러움 자체는 결함으로 집계하지 않았습니다.

## 반복 실행·성능·종료

동일 프로세스에서 4개 맵을 4회 순환해 **16회 추가 로드/해제**하고 일반/ICE를 번갈아 적용했습니다.
순환 종료 후 노드 수 110, orphan 0, Object 수 1,891로 동일했습니다.
고정 메모리는 약 169.425MB → 169.458MB로 약 33KB 증가했습니다.
짧은 표본에서 큰 누적·누수 징후는 없었으며 장시간 누수 없음까지 보증하지 않습니다.

실제 Metal의 LEVEL 04 일반 모드에서 약 7.24초 실행, 준비 프레임 제외 240개 표본을 수집했습니다.
실제 캡처 픽셀은 3024×1701, 60FPS 제한에서 관측 FPS 60, 물리 처리 중앙값 약 1.00ms,
최댓값 약 1.98ms였습니다. draw call은 표본에서 222입니다.
정지된 시작 구간의 짧은 측정이므로 모든 맵·다른 GPU·센서 병행·오랜 플레이 성능의 보장은 아닙니다.
headless 성능 모니터 일부가 0 또는 의미 없는 FPS를 반환한 값은 성능 판단에서 제외했습니다.

검사 로그에서는 종료 시 ObjectDB/RID 누수·GDScript 오류를 발견하지 못했습니다.
ICE의 셰이더 오류는 별도로 남아 있으며 프로세스 종료 코드 0만으로 성공 처리하지 않았습니다.

## Windows EXE 제작 전 사전 점검

이번에는 Export/EXE를 생성하지 않았으므로 아래는 정적 검토와 향후 확인 항목입니다.

- **QA-001을 먼저 해결하고 실제 렌더링을 재검사**해야 합니다. 현재 ICE 테마를 완성 기능으로 배포하면 안 됩니다.
- LEVEL 03·04 빌더는 `FileAccess.get_file_as_string()`으로 원본 OBJ/MTL을 읽습니다.
  로컬 파일은 존재하지만 `export_presets.cfg`가 없어 원본 텍스트의 배포 포함 정책은 미설정입니다.
  나중에 Export를 요청받으면 원본 OBJ/MTL 포함·열기까지 확인해야 합니다. 현재 누락 사고가 발생했다고 단정하지 않습니다.
- 실제 런타임 경로는 `res://`, `user://`, Python `Path(__file__)`를 사용합니다.
  개발 보고서에 적힌 `/Applications/`, `/dev/cu.*`, `/tmp`는 런타임의 고정 USB 경로와 구분합니다.
- Python 중계는 pySerial 3.5와 Python이 필요합니다. `.bat`는 현재 `py -3`/가상환경을 전제로 하며 독립 EXE가 아닙니다.
- Windows COM 포트는 자동 탐색하도록 작성됐고 POSIX exclusive 옵션은 조건 분기합니다.
  Windows 실기기·USB 드라이버·방화벽·보안 프로그램과의 실제 동작은 미검증입니다.
- 고유 ID 역할·축·반전·영점은 Git 제외 로컬 설정입니다. 새 PC에서는 최초 등록과 C 보정이 필요합니다.
  향후 독립 배포에서는 설정 저장 위치·쓰기 권한·Python 없는 실행 방법을 별도 검증해야 합니다.
- QA-002~005는 행사 시야와 로그 관리에 영향을 줄 수 있으므로 사용자 판단 후 수정 여부를 정하세요.

Godot의 원본 파일 Export 정책은 [공식 FileAccess 문서](https://docs.godotengine.org/en/stable/classes/class_fileaccess.html)와
[Export 안내](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html)를 참고합니다.
