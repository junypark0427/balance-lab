## 3. macOS 내장 게임 화면의 입력 문제 진단

최초 커밋 README에 다음 사용자 확인 과정이 이미 남아 있습니다.

1. 상단 삼각형 버튼으로 실행했지만 키를 눌러도 진단 `Events=0`.
2. 내장 게임 화면의 Input / 2D / 3D 중 **Input**을 선택하고 화면을 클릭.
3. Events가 증가하고 A·↑에서 P1/P2와 X/Z 값이 바뀌며 실제 플랫폼도 기울어짐.

따라서 당시 확인된 차이는 이벤트 전달 단계의 모드/포커스였습니다.
자동 `Input.parse_input_event()` 성공만으로 실제 키보드 전달까지 검증했다고 판단하지 않은 사례입니다.
그러나 각 대화와 진단 UI 추가의 개별 시각은 확인되지 않아 날짜를 임의로 나누지 않았습니다.

근거: `git show 4ff61fc:README.md`, [TiltInput](../../scripts/tilt_input.gd), [INPUT TRACE](../../scripts/input_debug.gd).
이 항목과 10월 23일의 별도 OS 키 탭 검사는 서로 다른 검증 기록입니다.
